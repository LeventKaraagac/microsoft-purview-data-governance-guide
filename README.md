# Data Governance with Microsoft Purview — A Practical Guide for SMBs

Part of the **Microsoft 365 Security Foundations** series — practical, production-tested guides for securing Microsoft 365 as a small or growing business.

A guide to classifying and protecting sensitive data in Microsoft 365 using Purview, written for small businesses that need real data governance — often to
meet a compliance obligation like GDPR — without an enterprise data team.

Small businesses handling sensitive or regulated data (health, financial, personal) who need a practical path to GDPR-aligned data governance without enterprise tooling or a dedicated compliance team.
